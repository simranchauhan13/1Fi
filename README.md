# 1Fi - (1Fi-Marketplace)

A React-based implementation of the 1Fi Marketplace feature.

## Features

- Browse products
- Search for products
- View product details
- Choose product variants
- Choose an EMI plan
- Proceed with the selected plan
- Loading and error messages
- Simple responsive design

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS

## Data

Product details, prices, variants and EMI plans are stored separately in a data file using sample data.

## Run Locally

npm install
npm run dev
